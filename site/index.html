Web component · React · zero dependencies

Principles

Three promises every component keeps.

  • Zero dependencies. Each component has a size budget, checked in CI.
  • Strict-CSP safe. No 'unsafe-inline', no eval, Trusted Types on. This site runs under that policy too.
  • Any framework, or none. Plain web components, plus native React where it helps.
